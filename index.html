🔧 Настройка синхронизации Firebase

Для синхронизации данных между устройствами нужно настроить Firebase:

  1. Создай проект на Firebase Console
  2. Добавь веб-приложение и скопируй конфигурацию
  3. Включи Realtime Database в разделе "Build"
  4. Вставь свою конфигурацию Firebase в код ниже (строка 320)

Без настройки Firebase данные сохраняются только локально!
