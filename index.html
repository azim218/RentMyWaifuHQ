Теперь важно: Настрой правила базы данных для работы приложения:

  1. Перейди в Realtime Database → Rules
  2. Замени правила на: 
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}
  3. Нажми "Опубликовать"

⚠️ Без этого приложение не сможет сохранять данные!
